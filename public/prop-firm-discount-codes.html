How prop firm discount codes actually work

The question behind "[firm] discount code" is usually "how much can I save, and what's the catch?" Here's the honest version — including the part almost no one writes down.

Why most "discount code" pages are full of codes that don't work. Two reasons. First, prop firm codes are promotional — tied to a campaign or an affiliate agreement — so firms rotate and retire them constantly, and a page that never shows its check date can't tell you which are still live. Second, and less obvious: several firms' affiliate terms forbid publishing discount codes publicly at all — on forums, coupon sites or pages like this — on pain of losing the account and any unpaid commission. So the "codes" you find scattered across the web are often scraped, guessed, expired, or posted by people who've broken the firm's rules to do it. That's the real reason the category is so full of dead strings. Where a firm doesn't permit a public code, the honest answer is a link, not a fake code — which is what you'll find below.

Why do prop firm discount codes expire?

Most are tied to a campaign, a season, or an affiliate's agreement, so firms rotate or retire them regularly. That's why this page shows a "last verified" date next to any code — and marks ones we couldn't verify rather than hiding them.

Can you stack more than one discount code?

Usually no. Most prop firms allow only one code per checkout, and stacking a public code on top of an affiliate link often cancels one or the other. If you have to choose, the code with the larger, clearly-stated discount is normally the safer pick — and always confirm the final price before paying.

Is the prop firm challenge fee refundable?

It depends on the firm. Some refund the challenge fee with your first payout once you pass and trade a funded account; others treat it as non-refundable. This changes the real cost of a challenge more than a few percent off the sticker price, so check each firm's own terms — we link to them below.

Do discount codes apply to every account size?

Not always. Some codes apply only to specific challenge sizes or product types, and some exclude the cheapest tiers. The discount percentage can also differ by account size. Where we know of a restriction, we note it next to the code.

How do you verify these codes are working?

We check each code we're allowed to publish at the firm's own checkout and record the date it last applied a valid discount. If a code stops working we mark it "Could not verify — [date]" and leave it visible, so you see the history instead of trusting a page that only ever shows green.
