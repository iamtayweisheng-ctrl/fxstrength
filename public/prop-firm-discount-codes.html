How prop firm discount codes actually work

The question behind "[firm] discount code" is usually "how much can I save, and what's the catch?" Here's the plain version.

Why do prop firm discount codes expire?

Most prop firm codes are promotional — tied to a campaign, a season, or an affiliate's agreement — so firms rotate or retire them regularly. A code that worked last month can silently stop working, which is why a code list is only useful if it shows when it was last checked. That date is the whole point of this page.

Can you stack more than one discount code?

Usually no. Most prop firms allow only one code per checkout, and stacking a public code on top of an affiliate link often cancels one or the other. If you need to choose, the code that gives the larger, clearly-stated discount is normally the safer pick — and always confirm the final price before paying.

Is the prop firm challenge fee refundable?

It depends on the firm. Some refund the challenge fee back to you with your first payout once you pass and trade a funded account; others treat the fee as non-refundable. This materially changes the real cost of a challenge, so it matters more than a few percent off the sticker price. Always check the specific firm's refund terms — we link to each firm's own terms above.

Do discount codes apply to every account size?

Not always. Some codes apply only to specific challenge sizes or product types, and some exclude the cheapest tiers. The discount percentage can also differ by account size. Where we know of a restriction, we note it next to the code.

How do you verify these codes are working?

We check each code at the firm's own checkout and record the date it last applied a valid discount. If a code no longer works, we mark it "Could not verify — [date]" and leave it visible rather than deleting it, so you can see the history instead of trusting a page that only ever shows green.

Are the links on this page affiliate links?

Yes — some are, and we say so plainly at the top of the page. An affiliate link may earn us a commission if you buy a challenge, at no extra cost to you. The codes themselves are public; you can use them whether or not you use our link. We're independent and don't rank the firms.
